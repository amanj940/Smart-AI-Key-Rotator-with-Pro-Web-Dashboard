# 🚀 OpenCode Smart AI Key Rotator & Pro Dashboard

موجه وموزع ذكي محلي لإدارة وتدوير مفاتيح الذكاء الاصطناعي المجانية من عدة مزودين (**Google Gemini, Groq, OpenRouter, Cerebras, Mistral**) مع لوحة تحكم ويب عصرية وقياس حي للسرعة والقدرة.

## ✨ المميزات
- **توجيه ذكي ديناميكي (Smart Routing):** يقيس سرعة الاستجابة (`ms`) وقدرة كل نموذج ويختار الأسرع والأقوى تلقائياً.
- **لوحة تحكم ويب Pro (`/ui`):** تبويبات مستقلة لكل مزود، كشف النماذج المجانية المتاحة، اختبار سرعة جماعي، وإيقاف/تفعيل المفاتيح بنقرة واحدة.
- **عزل تلقائي للأخطاء (Auto-Cooldown):** يتجاوز أي مفتاح ينتهي رصيده (`429`) فوراً دون انقطاع جلسة البرمجة.

## 🛠️ التشغيل السريع
1. ثبّت المكتبات: `pip install -r requirements.txt`
2. انسخ `config.example.yaml` إلى `litellm_config.yaml` (أو أضف مفاتيحك من الواجهة).
3. شغّل الخادم: `python3 gemini_rotator.py`
4. افتح لوحة التحكم: `http://localhost:4000/ui`
